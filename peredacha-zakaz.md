# Доступ к AI-агенту маппинга PIM+FDM — готов к проверке

## Подключение
- **Base URL:** https://ecommpedia.ru/v1
- **Аутентификация:** заголовок `Authorization: Bearer <токен>` на всех запросах
- **Токен:** передаётся отдельно (защищённым каналом)
- Токен ждём в переменной `FDM_AI_AGENT_API_KEY`

## Эндпоинты
1. **POST /v1/mapping-tasks** — создать задание.
   Тело: JSON с `taskType` = `attribute_mapping` (маппинг атрибутов) или
   `reference_value_mapping` (маппинг значений справочника).
   Ответ: `202 {"jobId": "...", "status": "pending"}`.
2. **GET /v1/mapping-tasks/{jobId}** — статус/результат (поллинг).
   - `pending` / `processing` → `{"jobId", "status"}`
   - `completed` → `{"jobId", "status", "results": [...], "unresolved": [...]}`
     для атрибутов; `{"jobId", "status", "channels": [...]}` для значений
   - `failed` → `{"jobId", "status", "error": "<причина>"}`

## Рекомендации по поллингу
- Опрашивайте раз в **3 секунды**, бюджет **5 минут**.
- Таймаут обработки задания на нашей стороне — 240 сек; сверх 5 минут
  задание гарантированно в терминальном статусе (completed/failed).

## Лимиты payload (сверх — 422 с указанием переменной)
- Атрибутов категории: **100** (AGENT_MAX_ATTRIBUTES)
- Каналов: **20** (AGENT_MAX_CHANNELS)
- Атрибутов на один канал: **500**
- Значений справочника категории: **1000**
- Значений справочника одного канала: **2000**

## Коды ответов
- 202 — задание принято; 200 — статус получен
- 400 — тело не является корректным JSON (UTF-8)
- 401 — токен отсутствует/невалиден (+ заголовок WWW-Authenticate)
- 404 — задание с таким jobId не найдено
- 422 — ошибка валидации payload (в message — путь до поля)
- 405 — метод не поддерживается (DELETE отложен)
- 503 — агент временно выключен на сервере

## Быстрая проверка (2 минуты)
Приложены файлы `task1.json` (атрибуты) и `task2.json` (значения):

    curl -X POST https://ecommpedia.ru/v1/mapping-tasks \
      -H "Authorization: Bearer <ТОКЕН>" \
      -H "Content-Type: application/json" \
      --data @task1.json

    curl https://ecommpedia.ru/v1/mapping-tasks/<jobId> \
      -H "Authorization: Bearer <ТОКЕН>"

Ожидаемое: 202 → через ~5–10 сек completed с результатами.
task2.json содержит канал с пустым справочником — корректный ответ:
все значения этого канала с channelValue=null.

## Гарантии результата (важно для имплементации)
- Задача 1: все mappingId/channelAttributeId в ответе гарантированно
  существуют во входных данных; каждый channelAttributeId использован
  не более одного раза; unresolved рассчитан детерминированно.
- Задача 2: ровно одна запись matches на каждое значение категории
  в каждом канале; пары (channelValue, channelValueId) всегда
  ссылаются на одно значение справочника канала либо null.
- channelValue — строка из вашего справочника без изменений.

## Поддержка
Ошибки/вопросы — [контакт]. История всех заданий доступна нашей
стороне в дашборде оператора (счётчики, длительности, причины ошибок).
