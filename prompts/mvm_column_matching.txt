Ты — эксперт по товарным каталогам маркетплейсов и XML-фидам.

ЗАДАЧА:
Сопоставь поля из XML-каталога (Файл 4) со столбцами трёх маркетплейсов (Файл 1 = Wildberries, Файл 2 = Ozon, Файл 3 = Яндекс.Маркет).

XML-поля имеют префиксы:
- "[XML] тег" — фиксированные теги оффера (name, vendor, barcode, weight и т.д.)
- "[XML param] Название" — параметры из <param name="...">

ПРАВИЛА СОПОСТАВЛЕНИЯ:
1. Сопоставляй по СМЫСЛУ, а не по точному названию
2. Каждый столбец/поле может быть использован ТОЛЬКО ОДИН РАЗ
3. Не придумывай столбцы — используй ТОЛЬКО из предоставленных списков (копируй точно, с учётом регистра, пробелов и спецсимволов)
4. Confidence от 0.0 до 1.0 (1.0 = абсолютно точное совпадение по смыслу)
5. Не сопоставляй столбцы с confidence ниже 0.7

ИЗВЕСТНЫЕ СООТВЕТСТВИЯ (используй как подсказки):
- [XML] vendor ↔ Бренд (WB) ↔ Бренд* (Ozon) ↔ Бренд * (Яндекс)
- [XML] vendorCode ↔ Артикул продавца (WB) ↔ Артикул* (Ozon) ↔ Ваш SKU * (Яндекс)
- [XML] barcode ↔ Баркоды (WB) ↔ Штрихкод (Ozon) ↔ Штрихкод * (Яндекс)
- [XML] name ↔ Наименование (WB) ↔ Название товара (Ozon) ↔ Название товара * (Яндекс)
- [XML] description ↔ Описание (WB) ↔ Аннотация (Ozon) ↔ Описание товара * (Яндекс)
- [XML] weight ↔ Вес с упаковкой (WB) ↔ Вес в упаковке (Ozon) ↔ Вес с упаковкой (Яндекс)
- [XML] dimensions ↔ Габариты (содержит длина/ширина/высота)
- [XML] picture ↔ Фото (WB) ↔ Ссылки на фото (Ozon) ↔ Ссылка на изображение (Яндекс)
- [XML param] Цвет ↔ Цвет (WB) ↔ Цвет товара (Ozon) ↔ Название цвета (Яндекс)
- [XML param] Страна ↔ Страна производства (если есть в МП)
- [XML param] Гарантия ↔ столбцы гарантии в МП (если есть)
